# QBOOK — Armwrestling Training

No-registration armwrestling workout builder.

- Shared read-only exercise catalog from Supabase.
- Build and edit workouts by movement group, equipment, level, and duration.
- Add personal exercises; store them, preferences, and training history locally in the browser.
- No account or authentication required.

Supabase project: QBOOK. The frontend uses only the public publishable key. Never expose a service-role or secret key in browser code.

Open `index.html`, or enable GitHub Pages from `main` / root. The former QuestBook app is preserved as `legacy-questbook.html`.
